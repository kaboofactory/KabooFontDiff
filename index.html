Kaboo Font Diff ユーザーマニュアル

⬇ Win64(.NET)版ダウンロード (約43MB)

Kaboo Font Diff は、インストールされているフォントを効率的に比較・管理・プレビューするためのWindowsアプリケーションです。特定のテキストが各フォントでどのように表示されるかを一覧で確認し、最適なフォント選びをサポートします。

主な機能と使い方

1. フォントセットの管理 (Font Sets)

用途に合わせて、比較したいフォントの組み合わせを「セット」として保存できます。

  • Select: 以前に作成したフォントセットを切り替えます。
  • New: 新しい空のフォントセットを作成します。
  • Rename: 現在のセットの名前を変更します。
  • Delete: 現在のセットを削除します。

2. フォントの追加と削除 (Manage Fonts)

PCにインストールされている全フォントから、セットに追加するフォントを選びます。

  • Available (左リスト): システムにインストールされているフォントの一覧です。
    • 検索ボックスを使用して、フォント名で絞り込みが可能です。
  • Add >>: 選択したフォントをセットに追加します。
  • Add All >>>: 検索ボックスで絞り込まれた全てのフォントを一括でセットに追加します。特定のファミリー（例: "Arial"）をまとめて追加したい場合に便利です。
  • << Remove: セット (右リスト) から選択したフォントを削除します。
  • In Set (右リスト): 現在のセットに含まれているフォントの一覧です。

3. プレビューの確認 (Preview Area)

画面右側のパネルで、追加したフォントの実際の表示を確認できます。

  • カード表示: 各フォントごとにカード形式でテキストが表示されます。
  • 削除ボタン (X): 各カードの右上にある「X」ボタンを押すと、そのフォントをセットから直接削除できます（Weeding out機能）。
  • ページネーション: 大量のフォントを追加した場合でも動作が重くならないよう、1ページあたり50件ずつ表示されます。画面下部の「< Prev / Next >」ボタンでページを切り替えてください。

4. 表示設定 (Display Settings)

プレビューの見た目をカスタマイズします。

  • Size (pt): フォントサイズを変更します。
  • Vertical Layout: 日本語の縦書き表示に切り替えます（右から左へ流れるレイアウトになります）。
  • Color Emoji: カラー絵文字を表示するためのモードです。
    ※ Vertical Layout と Color Emoji は同時に有効にできません。
  • Text Color / Back Color: 文字色と背景色を変更します。ダークモードの確認などに便利です。
  • Quality: 描画品質（アンチエイリアス設定）を変更します（SystemDefault, AntiAlias, ClearTypeなど）。

5. テキスト入力 (Text)

プレビューに使用するテキストを自由に入力できます。

  • テキストボックス: ここに入力した内容がリアルタイム（入力完了後）にプレビューに反映されます。
  • プリセットボタン:
    • 123: 数字のサンプル
    • ABC: アルファベットのパングラム (The quick brown fox...)
    • 漢: 漢字・ひらがな・カタカナのサンプル
    • Text: 長文テキスト (Lorem ipsum...)
    • Emoji: 一般的な絵文字セット
